# V14 发布说明（2026-11-05）

- 树状图及分支分布图支持全屏，点击按钮或 Alt+Enter，按钮可退出。
- 固定右下角悬浮「新增会员」按钮，管理员模式可用。
- 旧版全员 CSV / XLSX 可通过“批量上传 > 导入旧版全员数据”预览并恢复（含父子账号与所有本人资金项目）。
- 原 V11 加密 .mtbackup 仍通过「恢复加密备份」入口恢复，必须持原密码。
- 旧数据恢复先读取、验证、预览，不立即写入；二次确认后一次性事务替换，失败整体回滚。
- 操作日志标明恢复者、人数。并发更新会导致预览失效。
- 老版的逐层汇总 Excel 不是完整全员文件，不支持恢复会员树。
- CSV / Excel 没有每天提现历史的日期，恢复时文件中的当日提现会视为恢复当日；累计总提现保留原数。旧版未保存的逐日流水无法复原。
- 服务器若没有配置 `DATABASE_URL` 会默认 SQLite 本地文件。在 Render 免费 Web Service 上部署/重启仍可能丢失数据库，请接入持久化数据库并长期备份。
