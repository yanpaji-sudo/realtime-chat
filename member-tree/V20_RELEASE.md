# V20 日报实时同步与每日结算

- 每次会员增删改、撤回、余额/提现导入均即时刷新当日各组汇总快照。`/api/tree` 的同步访问也会刷新快照；报表页每次常规轮询都会重新读取报表。
- 报表支持「前一天」「后一天」查看历史日期、保留各组与全盘数据、以 `今日余额−前一日最后已记录余额` 计算「泡沫」，正负均可见。
- 同日重复上传只覆盖 `daily_withdraw_cents` 和 `daily_withdraw_ledger`，当日不会立即累加 `total_withdraw_cents`；在跨日结算时通过 `daily_withdraw_credit` 追踪已计金额，原子地一次性补记差额；可避免重复累计。
- 数据库升级为增量添加 `daily_withdraw_credit` 与 `daily_business_closes`，**不清空或重置会员记录**。升级时迁移之前版本已计入累计提现的账目，避免再次入账。
- 每日结算后台任务仅在服务仍在线时尝试临近 00:00（北京时间）捕获最新状态。Render 免费服务可能休眠或重新部署，无法承诺严格 00:00；此时系统在下次启动时使用上一个已保存的快照，并明确标记为「非精确24点」。这是持续在线基础设施/真正持久化数据库无法被代码替代的限制。
- 所有新增快照、结算与已计提现元数据都纳入管理员的加密备份和恢复流程。旧版 V19 加密备份仍可以恢复。
