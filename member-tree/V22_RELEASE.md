# V22.0：分支图三项工具、分组专注模式和个人视图保持

- 「会员树状图」「分支分布图」两页均显示风险月龄提示、当日提现蓝色光圈、纵横排列切换。
- 分支图工具区另放可见按钮，提现会员额外显示当前当日提现金额，点击关闭恢复。
- 选择 01、02、03、06、08 小组时只展示该组全部层级的成员，默认显示全部小组。
- 展开/折叠、缩放位置、画布平移、组别选择保存至当前浏览器标签页的 sessionStorage，不写入共享数据库，不影响其他用户。
- 后台十秒自动同步会员数据时保留当前画布 transform，而不是每次重新适应屏幕。
- 明确风险提示只是入会月龄红色浓度，不是财务风险预测。
- 本次只改 `static/` 文件，后端程序、表结构、资金计算、账号及环境密码均不变。

### 验证
- 16 项服务端自动测试通过；Node 前端测试通过；Chromium 离线模拟多人更新后保持视角、分组隔离、颜色圈、纵横切换通过。

### 已知风险
- 服务器临时 SQLite 的存储风险独立于本次客户端改动，源码归档不包含用户数据库。
