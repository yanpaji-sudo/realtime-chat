# V24 分支颜色与独立节点风险评估

- 平时按七色卡显示：今日新增绿色蓝框；未满1月浅绿；满1月浅白绿；满2月白；满3月淡蓝；满4至5月中蓝；满6月及以上深蓝。
- 风险评估属于前端只读模式；每个会员按该会员本人及全部下级团队的累计建仓减总提现，与团队余额比较。
- 四档无重叠规则：负数/亏损深红，0%至不足10%淡红，10%至不足20%淡绿，20%以上深绿。余额0或负数单独灰色无法评估。原用户口径10%—20%同时覆盖淡红和淡绿，采用四档清晰划分。
- 五组按会员树各节点独立评估，列出深红+淡红数量，支持展开风险明细、账号定位。非客观财务风险评估，特别是“建仓-提现”不能直接理解为企业真实利润。
- 不更改后台数据接口、登录、管理员、数据库结构；V18独立测试版不受影响。
