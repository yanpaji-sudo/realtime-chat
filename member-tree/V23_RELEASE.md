# V23 | 分支图超紧凑工具栏 + 五组 AI评估（规则分析）

- 分支分布图：标题、精准定位、小组筛选、风险提示、提现光圈、AI评估、缩放、适屏、展开、全屏和CSV导出共用一条29px控件行，工具栏整体约42px；窄窗口可水平滚动，删除第二排重复控件。
- 删除分支图额外说明、底部说明与独立入会色卡图例行，不再占用画布顶部高度。
- 风险提示按需显示为画布内浮层小标签，而非推挤树状图；只体现加入月份的颜色集中度，不代表真实投资/财务风险。
- 撤销纵向排列切换，固定使用从左往右的树状图布局，原缩放、拖动、分组、搜索和提现高亮保留。
- `AI评估`：五组（01/02/03/06/08）基于当前载入会员的只读规则分析，比较团队人数、今日新增、建仓、提现、余额、人均余额、当日差额及长期加入成员占比，给出抽样核查建议。非外部大模型服务，不自动操作任何会员账户，不推断未记录的历史。
- 不修改 app.py、数据库结构、会话鉴权、管理员密码、会员原始数据及导入导出逻辑。

验证：16项 Python 服务端测试通过；9项 Node JS规则测试通过；Chromium 浏览器 UI检查通过（工具栏约42px、5组AI评估卡片、风险浮层）。
