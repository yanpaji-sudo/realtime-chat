# V15：今日报表总览与月度分析

本版本基于 V14，新增「今日报表总览」菜单。

## 统计范围

- 当天报表：分组 01、02、03、06、08、其他（若有）、总计（全部有效会员）。分组由会员树最上层的根账号确定。
- 本月逐日：全盘日历日对比，或单独选择以上五组；可切换月份、按日期正序/倒序，导出 Excel。
- 图表：当日新增建仓与提现柱状比较，逐日团队输赢趋势折线图。

## 字段口径

- 今日裂变：今天加入会员的数量。
- 今日投注：目前该团队人数（注意这里并非实际下注笔数）。
- 投注对比：今日人数－昨日人数快照；缺少昨日数据时显示「未记录」。
- 今日充值：今天加入会员的本人建仓合计。
- 今日提现：今天团队提现合计；以北京时间日期关联当日导入数据。
- 手续费：今日提现金额×10%，按分取整。
- 团队输赢：今日充值－今日提现。
- 打码量：昨日记录余额－今日记录余额的正向下降部分，若余额上升则为0；缺少昨日快照不计算。
- 余额：当日记录的团队总余额。
- 平均余额：团队总余额÷团队人数。
- 本月收益：本月每日团队输赢累计，缺少任意一天历史快照则不冒充完整累计。

## 数据可靠性

首次安装只能从安装之日起记录日快照；旧日期不能从最新余额准确推算。历史快照是在打开报表时采集的最新值，**不等于前一日24:00精确结存**。免费服务器可能休眠，不能保证定时采集。若需严格24:00，请使用持续运行的服务器和定时任务，并验证 PostgreSQL 持久化数据库。

## 其他改动

- 首页六个摘要卡片：会员总数/昨日/今日，今日新增人数/存款，全盘裂变，平均余额/总余额，昨日余额和今日余额变化。
- 节点「直推」「团队总计」文字与后者字号加大；每日新增存款、月度裂变目标提示，以及连续低裂变天数（只依据确实采集过的日期）。
- 排行榜第二层账户可设置并更改团队名称，只显示二级账号，统计其全部后代。
- 加密备份新增报表历史、队名、每日裂变快照；恢复旧版文件仍兼容。

部署需确认当前服务启用持久化数据库。旧的本地 SQLite 在 Render 免费运行环境中可能随重新部署丢失。保留8名管理员密码配置，不创建或硬编码新密码。
