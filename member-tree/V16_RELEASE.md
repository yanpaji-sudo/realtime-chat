# V16 首页与报表修正

1. 首页从六张摘要卡片扩充至九张，新增「今日提现」「今日输赢＝今日新增建仓－今日提现」「今日团队总余额」。统计均基于会员树的同一份当日数据。
2. 金额和比例仅在显示时取整数，不改变数据库中的分、累计提现或实际小数精度。颜色保持：提现有数为红、输赢正绿负红零黑。
3. 节点指标栅格和提示气泡支持自动换行，长鼓励语不超过卡片边界。
4. 「今日报表总览」支持管理员编辑单一日期及小组的五项基础报表数字：会员人数、新增人数、新增建仓、今日提现、团队总余额；手续费、平均余额、当日输赢、月度累计收益随之重算。全盘总计根据各组自动合并，不允许手动直接覆盖。
5. 报表编辑单独存储到 report_manual_overrides，原会员表和原始日快照均不变；可恢复自动数据，保留审计记录与并发版本检查。可编辑数据仅限已采集日快照；缺少历史数据不会凭空填0。
6. 管理员加密备份/恢复包括报表修正记录，保持旧版备份兼容。
7. 保留八位管理员密码环境变量 ADMIN_USERS_JSON 等现有登录配置，不硬编码或重置密码。
8. 第1、2层本人建仓可填写正数，第3层及以下继续限制5000/10000。

## 测试
Python回归12项（分组运行）通过，Node规则3项通过。无网络静态浏览器测试中：三卡显示及报表编辑弹窗加载正常，无脚本错误；本地Loopback URL因浏览器安全限制无法访问，不代表正式服务测试。
