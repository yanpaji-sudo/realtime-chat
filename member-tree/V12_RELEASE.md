# V12 会员树状统计系统——团队指标与多周期排行

此包为 V11 正式后端的非破坏性迭代。原有8位管理员的 `ADMIN_USERS_JSON`、登录密码和权限检查未改变。

## 本次显示变更
- 会员卡片增加：本月团队新增人数、团队平均余额、团队输赢、当日裂变比例、本月裂变比例，全部按本人及所有下级统计。
- 团队平均余额 = 团队当前余额总和 / （本人+所有下级人数）。小于13000绿色，大于13000红色并显示“💣 炸弹来喽”，恰好等于13000黑色。
- 团队输赢 = 团队建仓资金 - 团队累计提现。正数绿色，负数红色，0黑色；数值小于10000时显示“你生病了吗”。
- 当日裂变 = 当天团队新增人数 / 团队当前总人数；低于1.5%红色（零为黑色），并显示“拖油瓶来喽”；高于1.5%绿色，等于1.5%黑色。
- 本月裂变 = 本月团队新增人数 / 团队当前总人数；低于45%红色，高于45%绿色，等于45%黑色。
- UI金额不显示人民币符号，仅保留数值；后台以分（cents）存储的金额未更改。
- 排行榜仅列第2层账号，成绩包含该会员本人及所有下级；新增当日、周、月、总榜，以及升序/降序。点击“详细”查看从第2层到实际最深层的**逐层汇总**，默认折叠。
- 周榜是北京时间本周一至今天的新会员建仓 - 本周已记录提现；月榜是本自然月同一口径；总榜是所有建仓 - 累计提现。

## 历史数据限制
此前版本只存“今天的提现”和“累计总提现”，不能凭累计数据还原每天的历史提现。V12新增独立每日提现快照表，只在未来成功上传当日提现后累计每日记录；上线前缺失的历史数据不会被猜测填充。若周/月统计期历史缺失，排行榜显示“不完整”提醒。

## 数据安全
- `members` 旧记录、账户关系和既有金额不会因V12迁移直接修改。数据库仅**新增** `daily_withdraw_ledger`、`daily_import_days`、`reporting_meta` 三张表。
- 每日提现快照在导入事务内一并写入；“撤回导入”同步恢复每日快照；加密备份包括新增的历史提现表并兼容旧版备份。
- **非常重要**：若 Render 仍未配置 `DATABASE_URL`，应用会继续使用免费服务的临时 SQLite，重新部署/重启可能丢失数据。部署到旧正式站之前，必须先将现有会员迁移到持久化数据库并验证完整加密备份。
